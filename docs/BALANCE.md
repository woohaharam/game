# Balance report

Generated by `npm run balance` — 400 simulated runs in 110.1s. Do not edit by hand.

Numbers come from a scripted bot, not from players. It kites at a fixed range, strafes, and dashes out of incoming fire with a reaction delay — competent, not optimal. Treat the survival rates as a **lower bound** on human performance and, more usefully, as a baseline that only moves when the game changes.
